# Content and data licensing

The MIT license in `LICENSE` applies only to source code and documentation
created for Open Azulejos.

## Metadata

Metadata explicitly published as part of an Open Azulejos dataset release is
made available under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/),
unless that release says otherwise. Personal data, unpublished moderation data,
credentials, and private source files are excluded.

## Photographs

A photograph is reusable only when its record explicitly identifies a license.
New contribution terms should request CC BY 4.0 permission from the photographer.
Existing photographs must not be treated as openly licensed merely because they
are visible on the website. Rights in a depicted tile or artwork are separate
from rights in the photograph.

The project owner should obtain Portuguese legal advice before the first public
dataset or bulk image release.
